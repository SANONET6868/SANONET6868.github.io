Privacy Policy

SANO NET PRO Backup
Updated: 20 November 2026

Purpose and operator

This utility is operated by the owner of SANO NET PRO for private application backup and recovery. It is not a public backup service.

Google data accessed

The utility uses Google OAuth authorization and the Google Drive API to create, upload, list and retrieve backup files and folders authorized for the application. Its configured drive.file permission limits access to files created or explicitly authorized for the app.

It does not request access to Gmail messages, contacts or calendars.

How data is used

Drive file names, identifiers, sizes and available checksums are used to transfer and verify encrypted backups. Downloaded backups are decrypted locally for recovery checks using the owner's backup password.

Backup contents may include application files, databases, voucher PDFs and private configuration. Sensitive backup contents are encrypted locally before upload. The backup password is not included in the encrypted backup uploaded to Drive.

Storage and security

Encrypted backups are stored in the owner's Google Drive and local storage. OAuth credentials and tokens are stored privately on the owner's device or server. They are not published on this website.

Sharing and advertising

The utility does not sell Google user data or use it for advertising or AI model training. Google processes transfers and storage as the selected Drive provider. Local recovery tools process downloaded backup data for the owner's verification and restoration.

Retention and deletion

Backups remain until the owner deletes them. The owner can delete Drive backups and local copies separately. Revoking Google access stops future authorized access but does not delete existing backups.

Google access can be reviewed or revoked at Google Account connections.

Public website

This informational website does not contain private backup files or a login form. It is hosted by GitHub Pages, which may collect technical visitor information under GitHub's privacy statement.

Google API policy

The utility's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
